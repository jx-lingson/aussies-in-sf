# Editing the Community page

All page headings and paragraphs live in `community.json`.

1. Open Community & open source on the website.
2. Click **Edit this page’s copy** to open this file in GitHub.
3. Click inside a quoted value to edit the words. Keep the JSON keys, quotes and commas. Add paragraphs as new entries in `sections` if needed.
4. Commit the change. Ask Codex to pull and publish the updated copy; a GitHub commit alone does not redeploy this Site.

You can also simply ask Codex to change any wording. There is no need to edit React or layout code.

The GitHub edit link is visible to everyone; only repository collaborators can commit directly. Other users can propose changes via a fork/pull request.
